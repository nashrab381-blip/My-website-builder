# KARAN Code Runner — Final

## Main features
- Clearly visible **NEW FILE** button
- New Folder
- Multiple files and tabs
- Nested folder paths, e.g. `pages/home.html`
- Quick HTML/CSS/JS file shortcuts
- File delete
- Find/Replace
- Local project save
- Desktop / Laptop / Tablet / Mobile / Mobile Landscape preview
- Preview zoom and pop-out
- Code Inspector

## Inspector detects
- Project files
- File sizes and line counts
- href/src/action references
- HTML page navigation references
- Missing local files
- CSS/JS dependencies
- HTML IDs and duplicate IDs
- CSS classes
- Hex/RGB/HSL colors
- JavaScript functions
- imports / require
- script and stylesheet usage
- basic HTML imbalance warnings
- TODO/FIXME
- console.log
- eval()

The color **editing** feature was intentionally removed. Colors are detection-only.

## File creation
Use **NEW FILE** and enter names such as:
- `index.html`
- `home.html`
- `about.html`
- `css/style.css`
- `js/app.js`
- `pages/contact.html`

Folders can be created with **FOLDER** first, then files can be created using a path such as `pages/contact.html`.

## Important
This is a browser-based frontend code editor. Actual execution of Python, C/C++, Java, Rust, Go, PHP etc. requires a secure backend or WebAssembly runtime. Do not execute untrusted code directly on a normal web server.
